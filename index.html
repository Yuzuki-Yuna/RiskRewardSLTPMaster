1. EA概要と主要機能 // OVERVIEW

1-1. 基本コンセプト

RiskRewardSLTPMaster v5.00 は、トレーダーが設定したリスク管理ルールを自動的に実行する次世代型リスク管理EAです。 口座残高、ストップロス距離、リスクリワード比率から、最適なロットサイズとSL/TP価格を自動計算し、成行・指値の両方に対応します。

1-2. 主要機能

  • スプレッド込みRR計算：成行注文時、BuyならAsk-SL、SellならSL-Bidの実距離をリスクとして計算し、正確なRRを維持します。
  • 自動リスク計算（ON/OFF切替）：
    • ON時：口座残高 × RiskPercent から逆算した最適ロットを自動計算
    • OFF時：ManualLotSize で指定した固定ロットを使用
  • リアルタイムラベル表示：チャート上にTP金額（+額）、SL金額（-額）、ロット/RR情報を表示
  • ワンクリック成行注文：BUY/SELLボタンでライン表示、EXEボタンで即座にエントリー
  • 指値注文の自動管理：SL/TP未設定の指値注文を検出し、自動でSL/TPとロットを最適化
  • マルチシンボル対応：FX、ゴールド/シルバー、インデックスを自動判別し、最適なPip値を適用
想定ユーザー： 「毎回手動でロット計算をするのが面倒」「常に一定のリスク％とRRでトレードしたい」裁量トレーダー向けに設計されています。

3-4. 自動リスク設定 ⭐ NEW

パラメータデフォルト説明
EnableAutoRiskPercent true 自動リスク計算の有効化
✅ true：口座残高とRiskPercentから最適ロットを自動計算
❌ false：ManualLotSizeで指定した固定ロットを使用

5-1. 基本的なワンクリックフロー

  1. チャート分析：テクニカル分析でエントリーポイントを決定
  2. 方向選択：
    • 買いたい場合：BUY ボタンをクリック
    • 売りたい場合：SELL ボタンをクリック
  3. ライン表示確認：チャート上に以下が表示されます
    • 🔴 赤いSLライン（ストップロス価格）
    • 🟢 緑のTPライン（テイクプロフィット価格）
    • 🏷️ 水色のSL金額ラベル（-xxxx）
    • 🏷️ オレンジのTP金額ラベル（+xxxx）
    • 🏷️ 白い情報ラベル（Lot:x.xx / RR:x.xx）
  4. 確認：表示された内容を確認
    • 想定損失額が許容範囲内か？
    • RRが設定通りか？
    • ロットサイズが適切か？
  5. 実行：問題なければ EXE ボタンをクリック
  6. 注文完了：
    • 成行注文が発注される
    • SL/TPが設定される
    • ラインとラベルが自動でクリアされる
    • ログに [Market Execute] Success. Lot=x.xx と表示される

5-2. LockMarketLinesモードの使い分け

A. 自動追随モード（LockMarketLines = false）推奨

  • 価格が動くたびにSL/TPラインが自動更新される
  • 常に現在価格から一定のSL距離・RRを保つ
  • スキャルピングや短期トレードに最適
  • 「今すぐ最適な位置でエントリーしたい」場合に便利

B. 手動ロックモード（LockMarketLines = true）

  • ラインが固定され、手動でドラッグ調整可能
  • 「ここまで来たらエントリー」という指定価格での成行に使える
  • 特定のサポート/レジスタンスを基準にしたい場合に便利
  • ライン位置から損益金額とRRを再計算して表示
ヒント： 最初は LockMarketLines = false で挙動を確認してから、必要に応じて true に切り替えるのがおすすめです。

5-3. 自動リスクON/OFF時の挙動

自動リスクON（EnableAutoRiskPercent = true）の場合：

// 計算ロジック
1. スプレッドを含めた実SL距離を計算
   BUY: 実SL距離 = Ask - SL価格
   SELL: 実SL距離 = SL価格 - Bid

2. 口座残高 × RiskPercent から許容損失額を算出

3. 最適ロット = 許容損失額 ÷ (実SL距離あたりの損失額)

4. 計算されたロットで成行発注

自動リスクOFF（EnableAutoRiskPercent = false）の場合：

// 計算ロジック
1. ManualLotSize で指定された固定ロットを使用

2. そのロットでの想定損益を計算してラベル表示

3. ManualLotSize で成行発注
🎯 どちらを選ぶべきか？
  • 自動リスクON：口座残高が変動しても常に一定のリスク％を維持したい場合。リアル運用推奨
  • 自動リスクOFF：シンプルに固定ロットで運用したい場合。バックテストやデモ検証に便利

6. 指値注文とポジション管理 // PENDING ORDERS & POSITIONS

6-1. 指値・逆指値注文の自動管理

MT5の注文機能で BUY LIMIT、SELL LIMIT、BUY STOP、SELL STOP を発注した場合、EAが自動的に検出して管理します。

管理フロー：

  1. 検出：OnTimer または OnTradeTransaction で新規注文を検出
  2. 条件確認：
    • シンボルが一致しているか？
    • MagicNumberが条件に合うか？
  3. SL/TP設定：
    • SL/TPが両方0の場合 → 自動でSL/TPを計算して設定
    • SLのみ設定済みの場合 → RRに基づいてTPを再計算して修正
  4. ロット調整（自動リスクON時のみ）：
    • 現在のロットが最適ロットと異なる場合
    • 注文を一旦削除して最適ロットで再発注（ReplaceOrder）

6-2. 既存ポジションの管理

指値注文が約定してポジションになった場合、または手動で成行注文した場合も自動管理されます。

管理対象：

  • SL/TP未設定のポジション：
    • エントリー価格から適切なSL/TPを計算
    • PositionModify で設定
  • TPがRR通りでないポジション：
    • 現在のSL距離からRRに基づいた正しいTPを再計算
    • ストップレベルを考慮して調整
    • 必要に応じて修正
注意： v5.00では、成行注文で既にSL/TPが設定されている場合、そのまま維持します（ライン位置を尊重）。 指値注文から約定したポジションのみRR再計算の対象となります。

7. スプレッド込みRR計算の詳細 // SPREAD-ADJUSTED RR

7-1. なぜスプレッドを考慮する必要があるのか？

成行注文では、BuyはAsk価格、SellはBid価格でエントリーします。 しかし、SL価格は常にBid（Buy時）またはAsk（Sell時）を基準とするため、 実際のリスク距離にはスプレッドが含まれます。

具体例：
パラメータ設定：StopLossPips = 30、RiskRewardRatio = 2.0
現在価格：Bid = 1.10000、Ask = 1.10002（スプレッド2pips）

従来のEA（スプレッド未考慮）：
Buy Entry: 1.10002 (Ask)
SL: 1.10002 - 0.00030 = 1.09972
TP: 1.10002 + 0.00060 = 1.10062
→ 実際のリスク距離 = Ask - SL = 1.10002 - 1.09972 = 30pips... ではない！
→ 実際は SL発動時はBidで判定されるため、実リスク = 1.10000 - 1.09972 = 28pips
→ RRがズレる！

v5.00（スプレッド考慮）：
Buy Entry: 1.10002 (Ask)
実際のリスク距離 = パラメータSL距離 + スプレッド = 30pips + 2pips = 32pips
SL: Bid - 30pips = 1.10000 - 0.00030 = 1.09970
TP: Ask + (32pips × 2.0) = 1.10002 + 0.00064 = 1.10066
→ 正確なRR 2.0を維持！

7-2. v5.00の計算ロジック

BUY注文の場合：

// エントリー価格
Entry = Ask

// SL価格（パラメータで設定した距離分だけBidから離す）
SL = Bid - StopLossPips

// 実際のリスク距離（スプレッド込み）
実リスク距離 = Entry - SL = Ask - (Bid - StopLossPips)
            = Ask - Bid + StopLossPips
            = スプレッド + StopLossPips

// TP距離（実リスク距離 × RR）
TP距離 = 実リスク距離 × RiskRewardRatio

// TP価格
TP = Entry + TP距離 = Ask + (実リスク距離 × RiskRewardRatio)

SELL注文の場合：

// エントリー価格
Entry = Bid

// SL価格（パラメータで設定した距離分だけAskから離す）
SL = Ask + StopLossPips

// 実際のリスク距離（スプレッド込み）
実リスク距離 = SL - Entry = (Ask + StopLossPips) - Bid
            = Ask - Bid + StopLossPips
            = スプレッド + StopLossPips

// TP距離（実リスク距離 × RR）
TP距離 = 実リスク距離 × RiskRewardRatio

// TP価格
TP = Entry - TP距離 = Bid - (実リスク距離 × RiskRewardRatio)

7-3. コード実装の該当箇所

UpdateMarketLines() 関数と ShowBuyLines() / ShowSellLines() 関数内で実装されています。

// 例：ShowBuyLines() からの抜粋
double ask = SymbolInfoDouble(g_ea_symbol, SYMBOL_ASK);
double bid = SymbolInfoDouble(g_ea_symbol, SYMBOL_BID);
double spread = ask - bid;

double slDistParam = CalculateSLDistance(g_ea_symbol);
int digits = (int)SymbolInfoInteger(g_ea_symbol, SYMBOL_DIGITS);

// BUY: エントリー=Ask, SL=bid-slDistParam
double slPrice = NormalizeDouble(bid - slDistParam, digits);

// 実際のリスク距離 = Ask - SL = slDistParam + spread
double actualSlDist = slDistParam + spread;
double tpDist = actualSlDist * RiskRewardRatio;
double tpPrice = NormalizeDouble(ask + tpDist, digits);
メリット： スプレッドが広いゴールドや早朝の通貨ペアでも、設定したRRが正確に維持されます。

8-3. ベストプラクティス

✅ DO（推奨）：

  • 最初はデモ口座で設定を試し、挙動を完全に理解してからリアル運用する
  • RiskPercentは口座残高の0.5〜2％程度に抑える（資金管理の基本）
  • スプレッドが広い時間帯（早朝・経済指標発表時）は成行エントリーを避ける
  • 複数銘柄で運用する場合、各チャートに個別にEAを設置する
  • 定期的にパネル表示を確認し、Managed数が想定通りか確認する

❌ DON'T（非推奨）：

  • RiskPercentを5％以上に設定する（リスクが高すぎる）
  • 自動リスクOFFで過大なManualLotSizeを設定する
  • 他のEAと同じMagicNumberを使う（干渉の原因）
  • ラベル表示を確認せずにEXEボタンを押す（想定外のロットになる可能性）
  • 複数の時間足に同じEAを重複して設置する（管理が複雑化）

8-4. トラブルシューティング

Q1. EXEボタンを押してもエラーになる

A: 以下を確認してください：

  • BUYまたはSELLボタンを押してラインが表示されているか？
  • 自動売買が有効になっているか？
  • 計算されたロットがMinLot未満になっていないか？（RiskPercentが小さすぎる可能性）

Q2. ロットが想定より小さい/大きい

A: 以下を確認してください：

  • RiskPercentが適切か？（1.0なら残高の1％がリスク）
  • StopLossPips / StopLossDollars が大きすぎないか？（SL距離が大きいとロットは小さくなる）
  • EnableAutoRiskPercentがfalseになっていないか？（falseの場合はManualLotSizeが使われる）

Q3. 指値注文のSL/TPが自動設定されない

A: 以下を確認してください：

  • 注文のシンボルがEAを設置したチャートと同じか？
  • MagicNumberが条件に合っているか？（MagicNumber=0なら、注文もMagic=0である必要）
  • EnableOnTradeTransactionがfalseの場合、TimerIntervalごとの監視になるため遅延が発生する

Q4. ラベルが表示されない

A: 以下を確認してください：

  • BUYまたはSELLボタンを押した後、チャートをスクロールしていないか？（ラベルは現在時刻の位置に表示される）
  • LockMarketLines=trueでラインが画面外にある場合、ラベルも見えない可能性がある
  • チャートを右クリック → オブジェクトリスト で RR_EA_Panel_Label_* が存在するか確認

1. EAの概要

本EAは「ストップロス距離 × リスクリワード比率 × 口座リスク％」から、SL/TPとロットを自動で組み上げるリスク管理特化型エンジンです。[file:1]

  • FX通貨ペア、インデックス、ゴールド/シルバー（XAU/XAG）を判別し、銘柄に最適化されたSL距離を自動計算します。[file:1]
  • 口座残高とRiskPercentから許容損失額を算出し、CalcOptimalLotで適正ロットを逆算します。[file:1]
  • チャート上のBUY/SELLボタンとSL/TPラインから、損失額・利益額・RR・ロットをリアルタイム表示します。[file:1]
  • 指値注文と既存ポジションのSL/TP・ロットを監視し、RRとリスク％がブレないよう自動修正します。[file:1]
想定ユーザー： 「毎回電卓を叩かずに、常に口座残高の〇％リスク＆RR固定でトレードしたい裁量トレーダー」。[file:1]

2. 導入とセットアップ

2-1. ファイル配置

  1. MT5を起動し、ファイル > データフォルダを開く をクリック。
  2. MQL5/Experts フォルダを開き、RiskRewardSLTPMaster_v4.73.mq5 をコピーします。[file:1]
  3. MetaEditorでコンパイルするか、MT5を再起動してEAリストを更新します。

2-2. チャートへの適用

  1. ナビゲータ ＞ エキスパートアドバイザ から、本EAを目的のシンボルチャートへドラッグ＆ドロップ。
  2. 「自動売買を許可する」にチェックを入れ、必要に応じてアルゴリズム取引も有効化。
  3. パラメータを好みに調整し、「OK」で起動します。
スコープ： EAはそのチャートのシンボル（_Symbol）と、MagicNumber条件に合致する注文/ポジションのみを管理します。[file:1]

3. パラメータ詳細

3-1. FX / メタル向けSL設定

項目説明
StopLossPips FX・インデックス用のSL距離（pips）。30なら30pips分をSL距離として扱います。[file:1]
StopLossDollars メタル（XAU/XAG/GOLD/SILVER）用のSL距離（USD）。10.0なら10ドル値動きをSL距離として使用します。[file:1]

3-2. 共通設定

項目説明
RiskRewardRatio リスクリワード比率。1.5なら、SL距離1に対してTP距離1.5となるようTPを自動計算します。[file:1]
TimerInterval OnTimer呼び出し間隔（ミリ秒）。注文監視・パネル更新の頻度を制御します。[file:1]
MagicNumber 管理対象マジック。0なら「マジック0＆同一シンボル」のみ管理対象になります。[file:1]

3-3. 自動リスクモジュール

項目説明
EnableAutoRiskPercent 口座残高に対するリスク％による自動ロット計算を有効化します。[file:1]
RiskPercent 1トレードあたりの許容リスク％。例：1.0なら残高の1％が最大損失になるようロットを決定。[file:1]

3-4. 成行ライン＆パネルの外観

項目説明
LockMarketLines false：価格に追随する自動モード。true：ラインをドラッグで固定するマニュアルモード。[file:1]
LineStyleSL / LineWidthSL SLラインの線種と太さ。[file:1]
LineStyleTP / LineWidthTP TPラインの線種と太さ。[file:1]
PanelFontSize / PanelTextColor 右下情報パネルのフォントサイズとテキストカラー。[file:1]
ButtonWidth / ButtonHeight BUY/SELL/EXEボタンのサイズ。[file:1]

3-5. 詳細挙動

項目説明
EnableOnTradeTransaction true：OnTradeTransactionイベントを使ったリアルタイム管理モード。false：OnTimer主体の監視モード。[file:1]
初期プリセット案： RiskPercent=1.0、StopLossPips=30、StopLossDollars=10、RiskRewardRatio=2.0 あたりから始めると挙動が把握しやすくなります。[file:1]

4. パネルとUI構成

4-1. 情報パネル（右下HUD）

起動後、チャート右下にHUD風のテキストパネルが表示されます。[file:1]

  • ===== EA v4.73 =====：バージョン表示。[file:1]
  • Type: Gold/Silver または Type: FX/Index：シンボル種別。[file:1]
  • Spread: x.x pips：現在スプレッド（pips換算）。[file:1]
  • Mode: RealTime / Timer：イベント駆動モードかタイマーモードか。[file:1]
  • Risk: x.x% (金額)：RiskPercentと現在残高から算出した許容損失額。[file:1]
  • SL: 30 pips / RR: 1.50 等：SL距離とRR。[file:1]
  • AutoRisk有効時：Lot: xx.xx と Loss: 金額 を同時表示。[file:1]
  • Pos/Ord: 全体ポジション数 / 全体注文数。[file:1]
  • Managed: EA管理対象ポジション数 / EA管理対象注文数。[file:1]

4-2. BUY / SELL / EXE ボタン

情報パネルの下に、右から EXE（オレンジ）・SELL（赤）・BUY（青） の順でボタンが並びます。[file:1]

  • BUY：BUY用SL/TPラインを表示・切り替え。[file:1]
  • SELL：SELL用SL/TPラインを表示・切り替え。[file:1]
  • EXE：表示中ラインからロットを自動計算し、成行注文を発注。[file:1]

5. 成行エントリー手順

5-1. ワンクリックフロー

  1. チャートを分析し、エントリーポイントが決まったら BUY または SELL ボタンをクリック。
  2. チャート上に、赤いSLラインと緑のTPラインが自動生成されます。[file:1]
  3. ライン付近にはラベルが表示されます。[file:1]
    • TP付近：+金額（想定利益額）。[file:1]
    • SL付近：-金額（想定損失額）。[file:1]
    • 中央：Lot: xx.xx / RR: yy.yy。[file:1]
  4. 表示される損失額・利益額・RR・ロットが自分のルールに合っているか確認。
  5. OKなら EXE ボタンをクリックし、EAに成行発注を任せます。[file:1]
  6. 発注成功時、ログにメッセージが出力され、SL/TPラインとラベルは自動でクリアされます。[file:1]
制限： AutoRisk（EnableAutoRiskPercent）が false の場合、EXE機能はエラーとなり使用できません。[file:1]

5-2. LockMarketLinesの挙動

  • false（自動追随モード）： 価格が動くたびにSL/TPラインも再計算され、常に一定SL距離＆RRを保ったまま最新価格でEXEできます。[file:1]
  • true（手動ロックモード）： ラインは固定され、ユーザーがドラッグした位置を保持。UpdateMarketLinesはその位置から損益金額とRRのみ再計算します。[file:1]

6. 指値注文＆既存ポジション管理

6-1. 指値・逆指値注文

  1. 任意の価格で BUY LIMIT / SELL LIMIT / BUY STOP / SELL STOP を発注します。
  2. その注文がチャートシンボルかつMagic条件に合えば、EAがOnTimer/OnTradeTransactionで検出します。[file:1]
  3. SL/TPが両方0：
    • StopLossPips / StopLossDollars と RiskRewardRatio からSL/TPを自動設定。[file:1]
  4. SLのみ入っていてTPが無い・ズレている：
    • SL距離 × RR から「あるべきTP」を計算し、TPのみ修正します。[file:1]
  5. AutoRisk有効時：
    • CalcOptimalLotでロットを再計算し、ズレていれば一旦削除→新ロットで再発注（ReplaceOrder）。[file:1]

6-2. 既存ポジション

  • SL/TP両方0：初期SL/TPを計算し、PositionModifyで設定します。[file:1]
  • SLはあるがTPがRR通りでない：
    • SL距離 × RiskRewardRatio からTPを再計算し、必要に応じて修正します。[file:1]
    • ストップレベルに抵触する場合は、AdjustSLTPForStopLevelで微調整してから反映します。[file:1]

7. 設定例と運用ヒント

7-1. 典型設定（例）

  • 残高：100万円（JPY口座）
  • RiskPercent：1.0（1トレード最大損失1％前後）[file:1]
  • StopLossPips：30（FX用SL距離）[file:1]
  • StopLossDollars：10.0（ゴールド用SL距離）[file:1]
  • RiskRewardRatio：2.0（RR 1:2）[file:1]
  • EnableAutoRiskPercent：true
  • LockMarketLines：false（まずは自動追随で挙動確認）[file:1]

7-2. 実際のトレードシーケンス例

  1. エントリー候補チャートにEAをセットし、上記設定を投入。
  2. BUYボタンを押してラインを表示、Lossラベルがおよそ1万円前後、RRが2.0前後になっているか確認します。[file:1]
  3. LockMarketLinesをtrueにしてSL/TP位置を微調整したい場合、ラインをドラッグしてから再度ラベル値をチェック。[file:1]
  4. 条件が揃ったらEXEを押して成行エントリー。以後、RRとリスク％はEAが一貫して維持します。[file:1]
  5. 他EA・裁量ポジションと混在させるときはMagicNumberを分けて干渉を避けるのが安全です。[file:1]
